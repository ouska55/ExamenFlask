Page de connexion 
L’utilisateur doit s’authentifier avec un identifiant et un mot de passe valides (par défaut : FatouBara / Munchies123) pour accéder à l’application.

Tableau de bord (index.html)
Une fois connecté, l’utilisateur arrive sur une interface principale qui centralise les accès aux autres pages.

Enregistrement des ventes (vendre.html)
Permet d’entrer les détails d'une vente : produit, quantité, prix, etc.

Suivi des ventes (afficher_vente.html)
Affiche les ventes enregistrées sous forme de tableau clair.

Gestion des stocks (stock.html)
Permet de visualiser et éventuellement mettre à jour les produits disponibles en stock.
